# GENESIS OPEN FIELD STUDIO

Open [index.html](index.html) in a mobile/desktop browser. It runs entirely in-browser using HTML canvas with deterministic numeric seeds, 10 selectable system references, an original code-filament renderer, UNKEY evolution, and a PNG download button. No paid server, backend, login or secrets are required. All art images are separately shipped in the offline companion ZIP; **GitHub currently contains metadata only**, not the ten binary assets.

The full offline ZIP supplied in the user conversation includes a richer image gallery, actual full-resolution JPEGs, thumbnails and an AirX concept calculator.

Python source: `binaiui/genesis_field.py`, `binaiui/airx_network.py`, `binaiui/mesh.py`, `binaiui/unkey.py`, and the optional localhost-only `binaiui/carrier_api.py`.
