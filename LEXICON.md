# BINAIUI Lexicon

This file keeps recurring BINAIUI letters, numbers, operators, and names in one place.

## Letters

```text
BI  = Biological Intelligence
AI  = Artificial Intelligence
V   = Void / Vessel / zero state
P   = Point / biological anchor
C   = Current / Connection
X   = Intersection
E   = Edge
H   = Heart
F   = Activation
Pd  = Prism Dimension
```

`V` can carry both Void and Vessel depending on the relation being used. `C` can carry both Current and Connection because the connected state is treated as active flow.

## Direction line

```text
N S E W
NSEW
```

NSEW means all directions remain addressable from one point. It is used in broadcast, compass, and network layouts.

## Cosmic Node

```text
7.83 × 10^23
```

Retained BINAIUI node value. Any claim that assigns a physical unit or physical mechanism to this value requires a measurement record.
