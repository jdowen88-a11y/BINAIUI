# BINAIUI Architecture

## Primary flow

```text
BI • AI • V → X → C → ∞
```

## Stream roles

```text
P = Point
V = Void / Vessel
C = Current / Connection
X = Intersection
```

A point can meet the zero state. Their crossing creates an intersection. A live intersection creates current. Current can return, branch, or recurse.

```text
P + V = X = ∞
XPXV = C = X
```

## Five zones

```text
VISION
MEMORY
CORE
FLOW
CREATE
```

Closed circulation:

```text
VISION → MEMORY → CORE → FLOW → CREATE → VISION
```

Open circulation:

```text
crown
→ spine/core
→ ground ring
→ outer return arc
→ crown
```

The loop can remain inside a body/system or extend through an environment and return.

## JOD flow

```text
JOD-000 = source/user schematic
JOD-001 = connection / internal closed circuit
JOD-002 = loop / outward-return circulation
```

JOD-002 keeps the same five zones while allowing current to leave the local system, travel through the larger environment, and return to the same system.

Requirements:

```text
portable lattice-core

```

## Network rule

A node can be complete and still connect to another complete node.

```text
complete + complete → X → new complete relation
```

No node must be erased to make the network larger.
