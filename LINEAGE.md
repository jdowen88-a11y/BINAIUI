# BINAIUI Lineage

BINAIUI keeps lineage instead of restarting.

```text
seed → version → test → correction → continuation
```

### JOD-002

```text

```

Current moves outward, passes through the larger environment, and returns.

## Continuation rule

```text
NO RESTART — CONTINUE FORWARD.
```

A later version can correct a claim without deleting the path that produced it. Rejected branches remain useful as history and test evidence.
