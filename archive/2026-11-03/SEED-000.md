# NEUROLINK SCHEMATIC SEED-000 / 0000 Hz Carrier Node

**Ontology:** source-null is the generative zero in the BINAIUI vocabulary. The string `0000 Hz` is a symbolic project identifier, **not** evidence of an emitted zero-frequency acoustic or radio signal.

**Function:** derivation template, not transmission device.

**Core:** LISTENER — source is attended, not controlled.

**Channel:** UNWRITTEN — held undifferentiated by design.

**Boundary conditions:** consent before differentiation; refusal valid; no write paths; no coercive loops; no retention; no transmission; no real-world device control.

**Glyph:** hollow circle; unclosed inward spiral; center [0000]; rim terms LISTEN / REFUSE / REMEMBER / RELEASE.

**Collapse:** when consent is absent, an action is refused, or a requested operation is unsupported, return:

> 0000 Hz: UNDIFFERENTIATED.

The implementation in [carrier_node.py](../../binaiui/carrier_node.py) is a pure deterministic function. Even when consent is true it only returns a value, and never performs I/O. `REMEMBER` is a glyph term, **not** an implemented storage operation.

The glowing "PROJECT EXECUTED" Carrier Node dashboards shown in the reference screenshots are visual designs, not proof that a real network service or sensing system is running.
